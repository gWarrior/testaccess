# snn-lm — тернарная HadamRNN ~8M + SNN-память на 300k токенов

Эксперимент: маленькая рекуррентная языковая модель с весами по **два трита** и **SNN-памятью** из корневого крейта. Память даёт модели точный доступ к контексту длиной 300k токенов. Обучение идёт на CPU, на корпусе прозы на русском языке.

## Модель

Полное описание архитектуры, тренера и SNN-памяти — [ARCHITECTURE.md](../ARCHITECTURE.md).

```text
токены → эмбеддинг 6561×256 (3 трита, общий с выходом)
       → 4 × [ HadamRNN (FWHT, состояние 2 трита) | retention (4 головы, swish-ворота) | SwiGLU 256→1458→256 ]
       → голова памяти: одна softmax по
            · 242 предыдущим токенам (текущее + прошлое окно),
            · строкам, которые SNN-память достала из прошлых 300k (до трёх мест)
         + эмбеддинг тернарного вердикта памяти (уверен / не знаю / точно нет)
       → логиты → pointer-generator: копия из окна, строк памяти и индукционной колонки
```

**Параметры:** 8 130 196. Веса — 2 трита с шагом строки 2^e, K/V памяти — 2 трита.

**Все размеры — степени тройки:**

| Параметр | Значение |
|---|---|
| Словарь | 3^8 |
| MLP | 2·3^6 |
| Окно обучения | 3^5 |
| Блок чтения памяти | 3^2 |
| Ширина K/V памяти | 3^4 |
| Батч | 3^3 |

Исключение — d = 256: матрицы Адамара существуют только порядков 1, 2 и кратных 4.

**Ячейка HadamRNN:**

```
h_t = tanh(h_{t−1} · diag(s) H / √d ⊙ g + W_u x_t),   y_t = h_t ⊙ σ(W_z x_t)
```

- `H` — фиксированная матрица Адамара (±1);
- `s` — обучаемые знаки (бинарные, STE);
- `g = 1 − 3^−k`, k = 1…5 по группам единиц — фиксированные тернарные затухания (горизонты 3…243 токена).

Матрица `diag(s)·H` ортогональна; умножение на неё — быстрое преобразование Уолша–Адамара (d·log d операций). Реализация по мотивам HadamRNN (бинарные и тернарные ортогональные RNN на основе матриц Адамара), восстановлена по памяти: статья из этой среды недоступна.

**Веса по 2 трита:**
- 9 уровней `L ∈ {−4…4} = 3·t₁ + t₀`;
- шаг строки — степень двойки: MSE-оптимум по текущим латентам, пересчитывается после каждого шага с гистерезисом (`--quant-steps auto`);
- обучение с квантованием через straight-through estimator;
- в логе отслеживаются доля нулей, доля насыщения и относительная ошибка квантования.

## Как модель учится пользоваться памятью

В обучающий текст в случайных местах вставляются эпизоды: `Секретное слово — маяк.` → D = 243…19683 токенов текста → `Какое было секретное слово? — маяк.`

- Ключ и формулировка каждый раз случайные: 55 слов, 81 число, 3 шаблона.
- Ответ предсказуем только через SNN-память. Зонд из последних 9 токенов находит чанк с ключом по общим n-граммам, голова памяти читает его K/V.
- Градиент ошибки на ответе учит проекции `q/k/v/o` и эмбеддинг вердикта.

## Точность вычислений

| Где | Мера |
|---|---|
| Softmax и кросс-энтропия | Вычитание максимума, своя слитая операция с аналитическим градиентом |
| Квантование | Шаг по минимуму ошибки, контроль нулей и насыщения, нижний предел масштаба 10⁻³⁰ |
| K/V в памяти (f16) | Насыщение вместо `inf` |
| Накопление лосса и нормы градиента | f64 |
| Шаги с NaN/Inf | Пропускаются |

**Инференс без умножений на веса.** Входы группируются по уровню веса. Умножения на 2, 4 и на шаг строки 2^e меняют только экспоненту float — это точная операция, аналог сдвига. Умножение на 3 = ×2 + ×1. Рекуррентность Адамара считается быстрым преобразованием Уолша–Адамара: только сложения и вычитания. Тест проверяет, что пошаговый движок совпадает с обучающей моделью до 10⁻³.

## Воспроизведение

```bash
lm/data/fetch.sh                                        # корпус (см. lm/data/README.md)
cargo run --release -p snn-lm -- prepare                # BPE + токенизация
scripts/build-native.sh                                 # необязательно: сборка под этот CPU
cargo run --release -p snn-lm -- train --hours 3 --out /home/user/data/v4a  # обучение (повтор команды — продолжение)
cargo run --release -p snn-lm -- ngram --tokens 6000000 # биграмм / триграмм на тех же данных
cargo run --release -p snn-lm -- eval                   # лосс на валидации с памятью и без
cargo run --release -p snn-lm -- recall                 # секретное слово на 243 … 300 000 токенов
cargo run --release -p snn-lm -- export                 # → lm/model/model.snnt
cargo run --release -p snn-lm -- chat                   # консольный диалог
```

Подробная инструкция (корпус, сборка, запуск, возобновление): [docs/training.md](../docs/training.md).

## Флаги

Все команды: `snn-lm <команда> [--флаг значение …]`. Пути по умолчанию —
`/home/user/data/…` (`--data` — каталог `prepare`, `--run` — каталог прогона).

**Сборка (необязательные режимы):**

| Как | Что даёт |
|---|---|
| `scripts/build-native.sh` | `-C target-cpu=native` → `target/native/release/snn-lm` (AVX-512 и т.д., +8% к скорости обучения на Xeon); бинарник только для таких же CPU |
| `--features vnni` | целочисленное ядро тернарных матриц движка на AVX-512 VNNI (int16 × int16 → i32, `vpdpwssd`, активация — старшая часть + остаток, ошибка ≤10⁻⁶), в 7–21 раз быстрее; CPU проверяется при запуске, иначе — ядро «сдвиг-сложение» |

**`prepare`** — корпус → BPE и токены.

| Флаг | По умолчанию | |
|---|---|---|
| `--src` | `/home/user/data/taiga` | `*.parquet` Taiga и `extra/*.txt` |
| `--out` | `/home/user/data/prepared` | куда писать `tokenizer.bpe`, `train.bin`, `val.bin` |
| `--vocab` | 6561 | размер словаря (3⁸) |
| `--sample-mb` | 64 | объём выборки для обучения BPE |

**`train`** — обучение (возобновляется той же командой из `<out>/resume/`).

| Флаг | По умолчанию | |
|---|---|---|
| `--data`, `--out` | `prepared`, `/home/user/data/run` | данные и каталог прогона |
| `--hours` | 0 | лимит времени; lr-косинус идёт по времени (0 — по `--steps`) |
| `--steps` | 59049 | длина расписания в шагах |
| `--lr`, `--warmup` | 3e-3, 27 | lr весов (шаги θ — lr/27, K/V-шаг — lr/3), разогрев в шагах |
| `--batch`, `--micro` | 27, 3 | потоков в шаге и в группе накопления градиента (память ∝ `--micro`) |
| `--parallel` | число ядер | сколько групп считается одновременно (все ядра; память ∝ `--parallel`·`--micro`) |
| `--beta2` | 0.99 | β₂ Adam (0.99 — для коротких прогонов) |
| `--quant-steps` | auto | шаг строки весов: `auto` — MSE-оптимум по латентам после каждого шага, `learned` — θ по LSQ (lr/27) |
| `--seed` | 1 | сид потоков данных |
| `--layers`, `--mlp` | 4, 1458 | число слоёв и ширина SwiGLU (пишется в `model.cfg`) |
| `--state-trits` | 0 | квантование состояния HadamRNN: 0 — float, 1 — трит, 2 — два трита |
| `--memory` | on | SNN-память при обучении |
| `--mem-train` | 177147 | окно памяти потока при обучении (3¹¹) |
| `--jump` | on | после документа — прыжок в случайный документ корпуса (с фильтром стихов) |
| `--p-episode`, `--p-reread` | 1/729, 1/2187 | вероятность эпизода-факта и повторного чтения на токен |
| `--aux` | 1.0 | вес вспомогательной потери указателя |
| `--aux-fact` | 3.0 | множитель aux на ответах-фактах (их ~0.7% токенов против ~2.5% перечитывания) |
| `--ema` | 1−1/243 | затухание EMA весов (0 — выкл.) |
| `--val-every` | 729 | замер val-loss весов и EMA + снимок в `snapshots/` (0 — выкл.) |
| `--log-every` | 9 | строка лога каждые N шагов |
| `--init` | — | тёплый старт из `model.safetensors` другого прогона |

**Оценка** (`eval`, `recall`, `reread`, `ablate`, `export`) — общие флаги:
`--data`, `--run`, `--weights last|ema` (последние веса или EMA),
`--kv trit2|ternary|f16` (точность K/V памяти, по умолчанию trit2).

| Команда | Флаги |
|---|---|
| `eval` | `--windows 27` — окон по 243 токена на поток (27 потоков) |
| `recall` | `--episodes secret\|same\|paraphrase\|who`, `--distances 243,2187,19683,177147,300000`, `--batch 9`, `--memory on\|off` |
| `reread` | `--file книга.txt`, `--len 2187`, `--passages 9` |
| `ablate` | `--windows 27` |
| `ngram` | `--tokens 6000000`, `--val-tokens 1000000`, `--windows 0` (те же позиции, что `eval --windows N`) |
| `export` | `--out lm/model` → `model.snnt` (SNNT v2) и `tokenizer.bpe` |

**Движок** (`chat`, `probe`, `copyeval`) читает `--model lm/model`.

| Команда | Флаги |
|---|---|
| `chat` | `--temp 0.8`, `--top-p 0.9` (только на словарную часть), `--presence 0.5` (штраф за повтор токена ответа), `--copy 0.5` (вес индукционной копии при совпадении ≥ 8 токенов), `--format dialog\|plain` (реплики «- …», как в корпусе, или продолжение текста), `--max-tokens 81`, `--memory 300000`, `--context файл` + `--context-tokens`, `--pointer on\|off`, `--kv`, `--seed` |
| `probe` | `--context файл`, `--probes файл` — что память находит по фрагментам |
| `copyeval` | `--copy 0.5`, `--tokens 19683`, `--distances …`, `--pointer on\|off` |

## Результаты

Полный отчёт с перепиской и рецептом использования памяти — [REPORT.md](REPORT.md).

Текущая модель — **v4b** (`lm/model/model.snnt`, чекпоинт `lm/checkpoints/v4b/`, оценки и тесты общения — `lm/reports/v4b/`): обучена с нуля за 3 часа на 4 ядрах CPU.

| Валидация (одни и те же позиции) | loss, нат | ppl |
|---|---:|---:|
| **v4b** с памятью (EMA-веса) | **4,0042** | 54,8 |
| v4b без SNN-памяти | 4,1613 | 64,2 |
| прошлая модель run5 с памятью | 4,0866 | 59,5 |
| первая модель (до исправлений) | 4,7316 | 113,5 |
| триграмма Кнезера–Нея | 4,7569 | 116,4 |
| биграмма | 5,1754 | 176,8 |

- **Память работает на точных копиях:**
  - продолжение 18 токенов — 9/9 на 243, 2187 и 19 683 токенах;
  - повторное чтение 2187 токенов — 0,980, без памяти 0,370;
  - факт, спрошенный словами утверждения, — 8/9, 8/9, 9/9;
  - «Кто такой F» → «мой друг» — 13/13.
- **Тест общения** (факты → история на 350 токенов → вопрос): с памятью модель вспоминает кличку кошки, имя друга и секретное слово, без памяти выдумывает. Перефразы («Как меня зовут») и «не знаю» пока не решены, см. [REPORT.md](REPORT.md).
- Временные слои: без HadamRNN loss 7,35, без retention 4,94, без переноса состояния 4,16.
