# Корпус для snn-lm

Корпус не хранится в git (~2.4 ГБ текста), он воспроизводится двумя командами:

```bash
lm/data/fetch.sh                                   # 5 шардов Taiga proza + проверка SHA-256
cargo run --release -p snn-lm -- prepare           # BPE 6561 + токенизация → /home/user/data/prepared
```

- **Taiga proza** — русская проза с proza.ru (`cointegrated/taiga_stripped_proza`), лицензия CC BY-SA 3.0. Средний текст около 12 тыс. символов: длинные истории, как нужно для проверки контекста.
- **Свои книги.** UTF-8 `.txt` файлы из `data/taiga/extra/` добавляются в корпус как отдельные документы. Так в экспериментах используется собственная копия «Хроник Амбера» (10 томов, ~3.5 млн символов, около миллиона токенов, то есть длиннее окна в 300k). Тексты под авторским правом в репозиторий не коммитятся.
- Валидация — каждый сотый документ.
