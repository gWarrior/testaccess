# Оценки и тесты общения: модель v4b

- **Версия модели:** прогон v4b, 2402 шага (3 часа), EMA-веса.
- **Упакованная модель:** `lm/model/model.snnt`.
- **Чекпоинт:** `lm/checkpoints/v4b/`.
- **Код:** ветка `claude/admiring-cerf-6y5ngx`, коммит `cea628f` — рецепт v4b; бинарник собран до правок v4c.
- **Размер модели:** 4 слоя × MLP 1458, d = 256, 8.13M параметров.
  - Веса — 2 трита, шаг строки — степень двойки.
  - Эмбеддинг — 3 трита.
  - Состояние HadamRNN — 2 трита.
  - K/V памяти — 2 трита.

| Файл | Что |
|---|---|
| `eval_ema.txt`, `eval_last.txt` | val-loss (27 потоков × 27 окон) с памятью и без |
| `recall_*.txt` | вспоминание фактов на 243 / 2187 / 19 683 токена: `same` — вопрос словами утверждения, `paraphrase` — отложенный перефраз, `who` — «Кто такой N» |
| `reread.txt`, `copyeval.txt` | повторное чтение 2187 токенов; точное продолжение 18 токенов |
| `scenario_dialogue.txt` | сценарий теста общения: факты → история (~350 токенов, дальше кольца внимания 243) → вопросы |
| `memtest_mem300000.txt`, `memtest_mem0.txt` | этот диалог в формате реплик `- …` с SNN-памятью и без неё (`--memory 0`) |
| `memtest_same_mem*.txt` | каждый вопрос отдельным прогоном, словами утверждения, `--temp 0 --format plain` |
| `memtest_questions_mem*.txt` | то же с перефразами — лексически недостижимы, ожидаемо не работает |
| `scenario_coherence.txt`, `coherence_s*.txt` | продолжение начатых фраз (связность текста) |

Все имена и места в сценариях выдуманы.
